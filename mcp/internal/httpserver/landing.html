Driftmower MCP

Driftmower MCP connects AI assistants to this Kubernetes cluster through the Model Context Protocol (MCP). Its tools discover available resources and admission policies, inspect workloads and resource usage, and provide provisioning guidance based on the cluster’s live configuration and your permissions.

mcp.codemowers.io provides general software engineering guidance for building and deploying applications. Use it alongside this server when you need both development guidance and facts about the target cluster.
